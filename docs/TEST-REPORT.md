# Реально выполненные проверки

Дата: 8 ноября 2026. Среда: Linux, Node 24.22.1, TypeScript 5.9, production-сборка Vite. Для CI настроен Node 22.

- `npm install` — зависимости установлены, lock-файл сохранён.
- `npm run typecheck` — успешно, ошибок TypeScript нет.
- `npm test` — 11 unit-тестов, успешно.
- `npm run build` — успешно; создан Service Worker с предварительным кешированием 91 локального URL (включая app shell, JS/CSS, manifest, все обложки и иконки). JS около 97 КБ gzip. Runtime без сторонних запросов.
- Playwright: **7/7 успешно**, финальный прогон 30,8 секунды. 7 браузерных сценариев на настоящем Chromium, production-preview, viewport iPhone 390×844. Проверены реальные IndexedDB и Cache Storage, не только мок-хранилище.
- Оценки обоих пользователей, частичный/полный просмотр Локи, заметки, редактирование даты, избранное, топ-10, история, фильтры, поиск на двух языках, сортировка, следующая рекомендация, случайный выбор, статистика — проверены.
- Перезагрузка, выключение сети, повторный запуск без сети, сохранение данных офлайн, новая вкладка без сети — проверены.
- Реальная замена версии Service Worker и кеша с ожиданием активации после закрытия старого документа — проверена. Заметки/статус в IndexedDB сохранились.
- JSON: скачивание настоящего файла, защищённый сброс, выбор скачанного JSON, подтверждение импорта и восстановление заметки — проверены. Некорректный JSON отвергается.
- Ширины 320, 375, 390, 430 и 1440 px — нет горизонтального переполнения. Скриншоты главной страницы, деталей и desktop сохранены в `docs/` и визуально просмотрены.
- Каталог: 38/38 дат вышедших фильмов дополнительно совпали с независимой таблицей; 33/33 сериалов совпали с TVmaze по всем включённым сезонам, датам начала и числу серий. Уникальность ID и обязательные поля проверены тестами.

## Исправления по результатам тестов

- Исправлен офлайн-перезапуск: `Vary: Origin` в ответах static-preview мешал найти JS/CSS в Cache Storage. Для собственных неизменяемых ресурсов Service Worker использует `ignoreVary: true`.
- Кнопке случайного выбора добавлено доступное имя, которое сохраняется в мобильном режиме с одной иконкой.
- Unit-тесты ограничены `src`, чтобы Vitest не пытался исполнять Playwright-сценарии.
- Уточнена дата первой цифровой доступности One-Shot «Агент Картер»: 03.09.2013.
- Следующая рекомендация учитывает даты незавершённых сезонов, не заставляя смотреть более поздний сезон перед ранним фильмом.

## Проверки с ограничениями

Физический iPhone и реальная установка на его главный экран недоступны в этой среде. Проверены manifest, иконки, standalone, safe areas и мобильная эмуляция Chromium. WebKit скачан, но запуск блокируют отсутствующие системные библиотеки GTK4/Graphene/Harfbuzz ICU/Manette/Hyphen/GLES; системный установщик и sudo в среде отсутствуют. Успешный запуск WebKit не заявлен. Публичный preview relay этой среды недоступен (`preview relay unavailable`). Локальный production preview запускался через Vite для браузерных тестов.

## Публикация

Пользователь предоставил https://github.com/lol5892/mcu . В репозитории был только начальный README `# mcu`; его содержимое и начальная история сохранены. Код подготовлен для GitHub Pages с автоматической сборкой через `.github/workflows/deploy.yml`.

При необходимости пользователь должен выбрать Settings → Pages → Source → GitHub Actions. Предполагаемый URL после успешной публикации: https://lol5892.github.io/mcu/ .
