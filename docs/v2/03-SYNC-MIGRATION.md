# Перенос и синхронизация

Исходная база `our-marvel`/`entries` не изменяется при входе в семейный режим. Отдельная база `our-marvel-family` содержит снапшоты по ID подтверждённого аккаунта и outbox с UUID операций. В локальном архиве по-прежнему работают все функции v1; облачные функции не подменяются локальными.

Перенос: обнаружение v1/JSON → экспорт копии → счётчики → подтверждение → атомарный SQL RPC → подтверждение результата сервером. Существующие облачные записи не перезаписываются; повторные импорты не дублируют серии. Старые персональные оценки staging привязаны к роли, но получить их в свои рейтинги может только соответствующий серверно удостоверенный аккаунт. Таня подтверждает свои оценки после приглашения.

Синхронизация: отдельные строки для эпизодов и персональных/посезонных оценок; Realtime + восстановление при возврате приложения + резервный polling. Только собственные оценки отправляются через RPC. Без сети отправляются в очередь отметки, оценки и сообщения; отправка/планирование писем, события и фото требуют сети. Черновик может ждать повторной отправки.

У каждой изменяемой записи версия. CAS-конфликт не затирается автоматически: интерфейс показывает действие и его JSON, предлагает экспорт и сохранение серверной версии, после чего изменение можно повторить по свежим данным. Серверные квитанции по `(auth.uid(), operation UUID)` обеспечивают идемпотентную обработку повторных запросов. Push использует отдельные стабильные ID и теги; подтверждение push-сервиса не выдаётся за показ на экране телефона.

Выход запрещён при непустой очереди; после выхода облачный кеш текущего аккаунта удаляется, локальная база v1 остаётся. API-токены и push-подписки не входят в экспорт.
