# После обновления до 2.1

Откройте существующую иконку с интернетом. Не удаляйте приложение и не очищайте Safari. Версия видна в настройках. Обновление откладывается, пока идёт активный сеанс, вводится текст, загружается фото или остаются действия синхронизации.

Проверка на двух iPhone: Антон выбирает фильм → «Начать просмотр вместе»; Таня открывает блок «СЕЙЧАС СМОТРИМ» на главной и присоединяется. Отправьте сообщение, реакцию и фото с подписью в обе стороны. Проверьте поле отправки с открытой клавиатурой. Сохраните фото в моменты, завершите сеанс и поставьте каждый свою оценку. Отметка просмотра требует отдельного решения и подтверждения партнёра.

Push на физическом iPhone проверяется отдельно: установленное PWA на iOS 16.4+, явное разрешение в разделе уведомлений, тестовое уведомление при закрытом интерфейсе. Автотесты сервера не подтверждают доставку APNs на заблокированный телефон. iOS не обязана запускать полностью закрытое приложение для обновления в фоне.

# Проверка и установка на двух iPhone после подключения production

Эти инструкции относятся к 2.0 **после** настройки Supabase/SMTP/Edge/cron, успешных онлайн-проверок и публикации. Выпуск выполняется по прежнему постоянному адресу. Статус проверки физических устройств указан в TEST-REPORT.md.

## iPhone Антона

1. Для этой семьи выбран чистый список: перенос прежних отметок не нужен. Не удаляйте приложение и не очищайте хранилище ради обновления. Если когда-нибудь понадобится перенос, сначала экспортируйте старый JSON.
2. После публикации закройте все окна PWA и откройте с иконки при наличии сети. Если вход выполняете в Safari, помните: его локальная база может отличаться от установленного приложения. Для переноса предпочтителен JSON из того PWA, где вы вели список.
3. Откройте основной сайт в Safari и войдите по подтверждающему письму со своей почтой. Уже созданная семья сохранится. В «Наши профили и приглашение» найдите «Вход с иконки iPhone», задайте личный пароль от 12 символов. После установки при необходимости выберите «Войти по паролю» с той же подтверждённой почтой. Пароль не нужно присылать в чат.
4. Пропустите перенос: общий список начинается с нуля.
5. В «Только наше» укажите точный email Тани и создайте приглашение. Передайте ссылку лично. Она одноразовая и действует 7 дней. Не публикуйте её в открытых каналах.

## iPhone Тани

1. Откройте приглашение в Safari. Войдите именно с тем email, который указал Антон, и подтвердите его кодом.
2. После подтверждённого входа приглашение принимается автоматически. Получится второй и последний разрешённый семейный аккаунт; отдельная кнопка принятия не нужна.
3. Прочитайте личное приветствие. Переходы ручные, текст не исчезает. Флаг первого просмотра хранится на сервере; переустановка не заставляет читать заново.
4. Пройдите инструкцию. Уведомления можно настроить позже, после установки PWA.
5. По желанию после приветствия в настройках профиля задайте свой пароль в разделе «Вход с иконки iPhone». Затем Safari → Поделиться → На экран Домой → Добавить. Запустите с иконки. Если вход потребуется повторить, выберите «Войти по паролю» и используйте ту же подтверждённую почту: iOS может разделять хранилище Safari и PWA. Сюрприз автоматически не повторится, но доступен в «Только наше → Посмотреть письмо от Антона ❤️».
6. Для этой семьи перенос старых оценок не требуется.

## Проверка синхронизации

На двух отдельных iPhone одновременно откройте один фильм. Антон меняет собственную оценку: Таня должна увидеть её без перезагрузки. Изменять оценку партнёра нельзя. Затем Таня отправляет комментарий: Антон видит его в той же теме. Если Realtime не приходит, зафиксируйте проблему отдельно; polling/перезагрузка не считаются доказательством проверки Realtime.

Отключите сеть на одном устройстве: измените отметку или напишите сообщение. Должна появиться очередь, а не ложный статус доставки. Включите сеть/вернитесь в приложение: на втором устройстве должна появиться одна операция. В конфликте версий должен появиться выбор с экспортом, без автоматического затирания.

## Настоящие push на каждом телефоне

Нужен iOS 16.4+, PWA с главного экрана, сеть и разрешённые уведомления. «Только наше → Уведомления → Включить / восстановить push». Нажмите сами — системный запрос без этой кнопки не появляется. Проверьте настройки тихих часов и часового пояса. Согласие на редкие предложения киновечера — отдельная настройка, по умолчанию выключена.

Нажмите «Отправить настоящее тестовое уведомление», затем закройте PWA и заблокируйте экран. Дождитесь работы минутного планировщика. Системное уведомление должно появиться и открыть приложение на нужном экране. Серверный статус «принято push-сервисом» сам по себе не доказывает доставку на экран. Проверьте Focus/«Не беспокоить»/разрешения iOS, если сообщения задерживаются.

Повторите: комментарий, общий чат, изменение оценки, новая фотография, письмо, приглашение/подтверждение/перенос просмотра и начало сеанса. На lock screen не должно быть личного текста письма или сообщения.

## Сюрпризы и планировщик

Отправьте тестовое письмо на несколько минут вперёд. До срока получатель не должен видеть строку, текст и фото даже после перезагрузки/прямого запроса API. После серверного tick письмо появляется и push отправляется один раз на каждое разрешённое устройство. Отмените другое запланированное письмо: оно не должно доставиться.

Создайте просмотр, подтвердите/перенесите его другим аккаунтом; собственное предложение нельзя принять самому. Для быстрых тестов назначьте напоминание за 1 час и событие немного дальше часа, дождитесь пересечения порога. Не выдавайте изменение локальных часов iPhone за проверку серверного scheduler. Отменённый просмотр не должен порождать устаревшие push.

## Фото и резервные копии

Загрузите снимок с геометками. Проверьте видимость второму участнику; посторонний/анонимный запрос не должен читать файл. Сохраните обработанный снимок и проверьте отсутствие GPS/EXIF. Export JSON не должен содержать access/refresh tokens, VAPID private key или push auth keys. Фотографии можно сохранить отдельно из полноэкранного режима.

Старые JSON v1 импортируются через мастер переноса. JSON v2 — архив всех доступных записей плюс безопасное восстановление отсутствующих собственных оценок и писем как черновиков; он не рассылает старые письма заново и не перезаписывает общие чаты/события автоматически.
