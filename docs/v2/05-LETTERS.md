# Письма друг другу

Реализован отдельный раздел: четыре оформления, заголовок/текст, фиксированный партнёр-получатель (без возможности отправки постороннему), черновик, немедленная отправка, отложенная отправка, отмена плана, удаление своего черновика, фото, раскрытие конверта вручную и повторная анимация, реакции, избранное, ответ, архив. Сервер запрещает переписывать доставленное письмо. Приватные черновики и отложенные тексты не загружаются клиенту получателя до серверной доставки.

«Прочитано» выключено по умолчанию и записывается только при согласии получателя. Push содержит фиксированную общую фразу, а не заголовок или содержание письма.

В UI-контрактном тесте два отдельных браузерных контекста отправили/открыли письмо и проверили отсутствие черновика партнёра. SQL-тест отдельно на PostgreSQL проверяет реальные RLS-политики, невозможность чужого редактирования, скрытие плановых писем, tick-доставку и недублируемое уведомление. Плановая доставка в production зависит от настроенного Edge dispatcher + pg_cron; она пока не объявляется проверенной в реальном проекте.
