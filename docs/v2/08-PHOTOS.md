# Приватные фотографии

Галерея/камера iPhone, JPEG/PNG/WebP/HEIC при декодировании самим браузером. Canvas перед отправкой уменьшает до 1800 px и перекодирует JPEG. Серверная Edge Function независимо проверяет подтверждённый аккаунт и зарегистрированный файл, читает поток с лимитом, декодирует JPEG с пределами памяти/разрешения и перекодирует только пиксели: геометки и остальные метаданные не переносятся.

Bucket `marvel-private` приватный. Клиент не имеет политик прямой записи. Загрузка проходит только через проверяющую функцию с серверным ключом в окружении Edge, не во фронтенде. Скачивание выполняется с пользовательским JWT и Storage RLS, затем отображается локальный Blob URL — публичные URL не создаются. Тексты/фото писем не видны получателю до доставки. Есть полноэкранный просмотр, сохранение снимка и удаление своих файлов.

Три Deno-теста фактически проверили удаление внедрённого EXIF/GPS, отказ не-JPEG и потоковое ограничение размера. Storage RLS и чужие вложения проверены SQL-тестами. Реальная загрузка в выбранный Supabase и камера физического iPhone пока не проверены.
