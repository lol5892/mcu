# Совместные сеансы

Карточка проекта открывает общий сеанс, второй участник присоединяется своим аккаунтом. В семье допускается один активный сеанс. Есть участники, статус, реакции, отдельный чат, фотографии, ручная минута и завершение. Видео не воспроизводится и не синхронизируется. После завершения доступны личные/посезонные оценки и переход к отметке просмотра.

Контрактный UI-тест проверяет создание, минуту и завершение. Серверные функции проверяют членство, версию и ID проекта, а уникальный индекс запрещает второй параллельный активный сеанс. Реальные push о начале и Realtime между устройствами ещё требуют проверки на выбранном сервере.
