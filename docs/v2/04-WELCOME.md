# Приветствие и первый вход

Содержание личного приветствия **не хранится в публичном репозитории**, тестовых фикстурах или JS-бандле. Серверная строка `mv_welcome` доступна по RLS только подтверждённому участнику с ролью tanya. Её создаёт bootstrap семейного пространства из заранее приватно provisioned содержимого. Точные пользовательские слова подготовлены в отдельном файле вне репозитория для загрузки в выбранный Supabase после подключения; в документации и скриншотах использован только синтетический тестовый текст.

После auth + одноразового приглашения первый показ требует записи `welcome_seen_at` на сервере. Флаг выставляется до открытия сцен, поэтому обновление/переустановка не сбрасывают сюрприз. Повторный просмотр доступен Тане в «Только наше». При ошибке сервера флаг не имитируется локально. Каждый экран переключается вручную; личный текст не исчезает по таймеру. Кнопка «К письму» пропускает вступительные анимации. Музыка не добавлялась; системный Reduce Motion отключает эффекты.

После письма — пять экранов знакомства. На последнем отдельная кнопка включает Web Push только после явного нажатия. Кнопка открытия вселенной сохраняет `onboarding_seen_at`. Инструкцию можно открыть повторно.

Контрактный браузерный тест проверил ручное управление, синтетический серверный текст, сохранение первого просмотра и повторное открытие из настроек. Это не подтверждение живой авторизации/доставки в Supabase: требуется подключённый production-проект и последующая проверка.
