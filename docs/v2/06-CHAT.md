# Чаты и реакции

Существуют общий разговор, комментарии проекта, сеанса и воспоминания. Сообщения имеют подтверждённого автора, время, ответ в пределах той же темы, редактирование/удаление только автором, спойлеры и пять реакций. Текст выводится React как текст, без HTML-вставки. Размер сообщения ограничен и UI, и PostgreSQL.

Новый текст без сети получает UUID и сохраняется в локальную очередь; интерфейс явно показывает, что он не доставлен. Контрактный браузерный тест проверил появление одного сообщения на тестовом API после восстановления связи. Реальная Realtime-подписка реализована в клиенте с RLS на сервере, но её доставка между двумя настоящими Supabase-аккаунтами требует подключённого проекта и остаётся отдельной проверкой.
