# Этап 1 — исходная версия

Рабочий production: https://lol5892.github.io/mcu/ . Исходный commit `b7ffe24`; исходный опубликованный build `15c601f`. На GitHub сохранены `backup/v1-before-2-0` и аннотированный тег `v1.0.0-before-2.0`. Разработка ведётся в `feat/family-universe-2`; main не используется для непроверенных изменений.

Стек: React 19, TypeScript 5.9, Vite 7, `idb`, Service Worker, manifest/Apple icons, автоматический GitHub Pages deploy. IndexedDB `our-marvel`, v1, store `entries`, ключ — стабильный ID проекта. 81 проект в существующем `catalog.json`; их ID и содержимое сохраняются. 11 исходных unit-тестов и TypeScript прошли до изменений. Предыдущие 7 E2E и HTTPS/offline smoke описаны в основном TEST-REPORT.

Модель v1: общий флаг и даты, массив ключей серий, две оценки, общая заметка, избранное. Модель не содержит удостоверенной личности, поэтому её нельзя отправлять в облако как авторизованные действия другого пользователя. Для переноса используется отдельный серверный RPC: отметки объединяются без дублей; оценки хранятся в staging по ролям и подтверждаются каждым владельцем аккаунта отдельно. Старый store никогда не удаляется.

Архитектура v2: добавляемые модули семейного пространства и отдельная база кеша, а не замена существующего store. Все облачные изменения проходят RPC с auth.uid(), членством, idempotency key и проверками версий. Публичная конфигурация содержит только Supabase URL и publishable/anon key; серверные ключи и приветственное письмо не входят в публичный JS или GitHub.

Публикация v2 заблокирована до реального развёртывания и проверок авторизации, RLS, Realtime, Storage и Edge Functions. Ненастроенный backend не имитируется.
