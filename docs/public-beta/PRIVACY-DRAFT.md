# Политика конфиденциальности — ЧЕРНОВИК

Это технический проект документа, не опубликованная юридическая политика и не основание начать сбор данных. Страна владельца: Россия. Контакт, подтверждённый владельцем: [Telegram разработчика](https://t.me/lol5892). Полное имя/статус оператора, адрес, сроки обработки и целевая аудитория ещё не утверждены.

## Назначение и данные

«Кино вдвоём» — приватный кинодневник пары. Предполагаются email и учётная запись Supabase Auth, имя участника, название пространства, членство, просмотры, эпизоды, оценки, впечатления до 200 Unicode-кодовых точек, даты киновечеров, фотографии и связи воспоминаний, трофеи/XP и квитанции уведомлений. Для Web Push используются адрес подписки и её технические ключи. Пароль передаётся Auth-провайдеру, приложение не сохраняет его открытым текстом. Платёжные данные не собираются: при подключении поддержки пользователь самостоятельно переходит к внешнему провайдеру.

## Доступ и хранение

Данные видят участники своей пары. Каждый редактирует только свои оценки и впечатления. Просмотры и общие события совместные. Другие пары не получают доступ через интерфейс, RPC, REST, Realtime или Storage. Администратор инфраструктуры технически имеет привилегированный доступ; нельзя обещать сквозное шифрование, которого нет. Секреты и аудит не доступны клиентам.

Текущий технический сервер — Supabase eu-central-1, только с вымышленными QA-аккаунтами. Размещение в Европе нельзя объявлять подходящим для обработки персональных данных российских пользователей без проверки локализации, трансграничной передачи и обязанностей оператора по 152-ФЗ. До выбора правомерной инфраструктуры реальные пользователи не регистрируются. Источник проверки: [официальный портал правовой информации, 152-ФЗ](https://pravo.gov.ru/proxy/ips/?docbody=&nd=102108261), [портал персональных данных Роскомнадзора](https://pd.rkn.gov.ru/).

На устройстве хранятся авторизационная сессия, разделённый по аккаунтам кеш, очередь несинхронизированных действий и черновики. Семейные фото не включаются в общий PWA-кеш. При выходе кеш аккаунта удаляется, о черновиках показывается подтверждение. Не следует пользоваться чужим профилем браузера для приватного дневника.

Фото оптимизируются с явно указанным ограничением качества/размера. Сервер заново кодирует пиксели и удаляет EXIF/GPS. Оригиналы должны оставаться у пользователя; сервис не обещает их сохранение. В бете до 10 серверных фото на пару, включая аватары, без автоматического удаления старых снимков.

## Экспорт, удаление и отключение

Экспорт JSON включает доступную своей паре историю, без токенов Auth, подписок push и секретных ключей. Фотографии скачиваются отдельно из полноэкранного просмотра.

Удаление собственного аккаунта, семейного пространства или отключение оформляются явным запросом в настройках. В технической бете запрос ставится в закрытую очередь и обрабатывается вручную; нажатие не выдаётся за мгновенное удаление. До реального набора нужно утвердить срок ответа, проверку личности, обращение с общей историей и резервными копиями. Для удаления общей вселенной требуется учесть права обоих участников. Новый партнёр не может быть подключён к данным прежней пары.

При реальном исполнении удаления необходимо отозвать сессии, удалить/анонимизировать личные данные согласно утверждённому основанию, отдельно обработать Storage и подписки устройств. Удаление auth.users само по себе не аннулирует уже выданный access token немедленно. Точная политика общей истории после отключения должна быть согласована, а не придумана приложением.

## Сторонние сервисы и согласования

Предполагаются выбранные оператором сервер/хранилище, статический хостинг, почтовый SMTP, сервисы доставки Web Push Apple/Google/Mozilla и, только по желанию, внешний сервис добровольной поддержки. Технический предпросмотр Sites имеет отдельный контроль доступа платформы. Реальные провайдеры и страны обработки перечисляются в финальной политике после выбора инфраструктуры. Рекламная аналитика и отслеживание содержимого впечатлений не добавлялись.

До публикации: сведения об операторе, правовые основания, согласия и их отдельная фиксация, локализация/трансграничная передача, сроки хранения и удаления, возрастные ограничения и необходимые уведомления регулятору должны быть проверены профильным специалистом. Этот черновик не обещает юридического соответствия.
