# Кино вдвоём — закрытая техническая бета 3.0

Отдельная копия стабильного «Наш Marvel» 2.5.3, для независимых пар. Исходное приложение https://lol5892.github.io/mcu/ и его семейная база не изменяются. В эту среду не переносились личные записи, фотографии, история или push-подписки исходной семьи.

Состояние: технический предпросмотр для владельца. Приём реальных участников и денег закрыт. 81 проект каталога, 82 трофея и XP 10/25/50/100 сохранены. Имена пользователей отделены от исторических ключей двух слотов; сообщения и письма не возвращаются.

`npm ci`, `npm test`, `npm run build`, `npm run test:sql`, `npm run test:public-sql`. Браузерные сценарии используют искусственные HTTP-фикстуры, SQL — отдельный Docker-контейнер; они не обращаются к личной семейной базе. Hosted QA запускается отдельно только против нового тестового проекта и затем отключается.

Основные миграции в `supabase/migrations` воспроизводят проверенную схему 2.5.3. Изменения только для новой пустой базы — в `supabase/public-migrations`; они намеренно отказываются работать при наличии семей или bootstrap исходной версии. Не сливать эту ветку в исходную main и не запускать её против старого проекта.
