# Наш Marvel

> **Разработка 2.0:** проверенная v1 продолжает работать по https://lol5892.github.io/mcu/ . Семейная версия разрабатывается отдельно, без замены production. [Статус и реальные проверки](docs/v2/TEST-REPORT.md) · [Настройка Supabase](docs/v2/SETUP.md) · [Два iPhone](docs/v2/TWO-IPHONES.md). До подключения и проверки реального backend новые онлайн-функции не объявляются готовыми.

Локальный семейный PWA-дневник MCU для Антона и Тани. React 19 + TypeScript + Vite. Без регистрации, сервера данных, API-ключей и внешних ресурсов во время использования.

## Запуск

```bash
npm ci
npm run dev
```

Production/PWA (Service Worker включён только в production):

```bash
npm test
npm run build
npm run preview -- --port 4173
```

Откройте http://localhost:4173. Для установки на iPhone нужен постоянный HTTPS-хост; локальный адрес на компьютере не заменяет публикацию.

## Возможности

- 81 проект (79 вышедших/идущих + 2 анонса): 38 фильмов, 33 сериала, 8 сюжетных спецвыпусков/One-Shots. Каталог на **08.11.2026**, сезоны внутри сериалов.
- Основной MCU, Defenders Saga, связанные сериалы с пояснением каноничности, альтернативная анимация, будущие фильмы — отдельные разделы.
- Отметки, две отдельные оценки 1–10, средняя пары, редактируемая дата, заметка, избранное. Оценки доступны после завершения проекта; снятие отметки/серии очищает оценки и дату, оставляя заметку и избранное.
- Сезоны и эпизоды; полное завершение вычисляется по всем сериям, а не ручному флагу сериала. Ещё не вышедший финал VisionQuest заблокирован до даты выхода.
- Следующее к просмотру, случайный выбор, фильтры, русско-английский поиск, порядок выхода, частичный порядок событий, фазы, рейтинг и год. Следующая рекомендация учитывает дату **следующего незавершённого сезона**, чтобы не предлагать Локи S2 раньше более ранних фильмов. В каталоге сам сериал сгруппирован по дате первого сезона.
- Наш топ-10, история, диаграммы и статистика.
- IndexedDB с неизменяемыми ID проектов, автоматическое сохранение, JSON-экспорт и импорт с предварительным подтверждением, проверка структуры, защита сброса вводом `СБРОСИТЬ`.
- PWA: manifest, PNG-иконки 192/512, maskable, Apple Touch Icon, standalone, safe areas, собственный Service Worker, офлайн-загрузка всего приложения и обложек. Все иллюстрации локальные и оригинальные.

## Каталог и обновления

Исходные данные: `src/catalog.json`. Каталог декларативный: новый проект или сезон добавляется в данные без изменения UI/логики. ID существующих проектов менять нельзя. `scripts/make-catalog.py` воспроизводит первоначальный каталог; при редактировании JSON напрямую не запускайте генератор, иначе он перезапишет ручные изменения.

`docs/CATALOG.md` описывает источники, границы каталога и ограничения хронологии. `docs/series-audit.json` содержит результат независимой сверки всех 33 сериалов с TVmaze. `python scripts/verify-series.py` обновляет аудит при наличии интернета; во время использования приложения API не вызывается. Точные даты представлены для американского проката/стриминга; даты других регионов отличаются. Русские названия новых проектов могут быть редакционными переводами.

Для нового сезона укажите номер, дату премьеры, количество серий и фазу. Для идущего сезона задайте `episodeDates` по каждой серии; без этого массивa все серии считаются доступными с даты премьеры сезона. Будущие проекты в `section: "future"` не входят в прогресс; после реальной премьеры обновите каталог и переместите проект в соответствующий раздел.

`npm run build` генерирует Service Worker с версией по хешу всех ресурсов. Новая версия ждёт закрытия старых окон. Индексированная база не удаляется при обновлении Service Worker и хранится отдельно от кеша. Для будущих изменений схемы используйте миграции `openDB`, не очищая store. На сайте нет кнопки автоматического удаления базы при обновлении.

## Резервные копии

Настройки → «Экспорт резервной копии JSON». Сохраните файл в «Файлы»/iCloud Drive. Импорт объединяет записи по ID; совпадающие заменяются копией после подтверждения. Формат содержит версию, дату экспорта и словарь записей. Неизвестные корректные ID сохраняются для совместимости с более новым каталогом. Перед импортом можно скачать текущую копию.

Синхронизации между телефонами нет. Safari и установленное PWA могут иметь разные хранилища: переносите JSON вручную. iOS может удалить локальные данные при очистке сайтов или нехватке места — делайте копии. Запрос постоянного хранения зависит от браузера.

## Установка на iPhone

1. Откройте опубликованный HTTPS-адрес в Safari.
2. «Поделиться» → «На экран Домой» → «Добавить».
3. Запустите приложение с иконки, откройте «Настройки» и дождитесь «Офлайн-кеш готов».
4. Затем можно открывать без сети, пока кеш сохранён.

## Проверки

```bash
npm run typecheck
npm test
npm run build
npm run test:e2e
```

11 модульных тестов проверяют каталог, 6/6 + 3/6 серий Локи, снятие отметок, оценки, фильтры, рекомендации по сезонам, резервные копии и контракт IndexedDB (fake-indexeddb).

7 сценариев Playwright используют реальный Chromium, production-сборку, настоящие IndexedDB/Service Worker и мобильную эмуляцию. Проверки: перезагрузка и сохранение обеих оценок/заметок/даты, избранное/топ/история, серии, фильтры, автономный перезапуск, JSON-экспорт/импорт, защита удаления, случайный выбор, статистика, активация нового SW без потери данных, новая офлайн-вкладка, ширины 320/375/390/430/1440 px и отсутствие JS-ошибок в основном пользовательском сценарии. Скриншоты находятся в `docs/`.

В данной среде Playwright запускается с системным Chromium `/usr/bin/chromium`; для другой системы установите Chromium через `npx playwright install chromium` и измените `executablePath` в конфигурации. WebKit был загружен, но среде не хватает GTK4 и других системных библиотек; тесты на нём и на физическом iPhone не заявлены. `BROWSER=webkit npm run test:e2e` доступен в среде с установленными зависимостями WebKit.

## Публикация GitHub Pages

Ветка `main`, workflow `.github/workflows/deploy.yml`. Он устанавливает зависимости, запускает unit-тесты/TypeScript/build, загружает `dist` и публикует Pages. Существующие проекты не используются.

При авторизованном GitHub CLI:

```bash
./scripts/publish.sh
```

Настройте Settings → Pages → Source → GitHub Actions, если API настройки Pages недоступен токену. Репозиторий должен быть отдельным и публичным для бесплатного Pages. Опубликованное приложение: **https://lol5892.github.io/mcu/** . Репозиторий: https://github.com/lol5892/mcu . Начальная история репозитория сохранена, исходный README находится в `docs/repository-initial-README.md`.

GitHub Pages включён с источником GitHub Actions. Публикация прошла успешно: https://github.com/lol5892/mcu/actions/runs/42521373046 . Проверен HTTP 200 и работа опубликованного приложения в мобильной эмуляции: обе оценки, заметка, перезапуск без сети, область Service Worker `/mcu/`, отсутствие ошибок JavaScript. Повторить проверку в этой среде: `node scripts/deployed-smoke.mjs`. Личные отметки этого теста живут только во временном браузерном профиле и не меняют данные пользователей.

Подробный отчёт — `docs/TEST-REPORT.md`.

Для Cloudflare Pages: создайте бесплатный проект Pages и загрузите **содержимое `dist`**, либо подключите этот репозиторий: команда сборки `npm run build`, каталог `dist`, Node 22. Серверные функции и база не нужны. Если интерфейс Cloudflare предлагает только Worker, выберите Workers & Pages → Create application → Pages → Upload assets.

## Ограничения и права

Это не сервис просмотра видео: ссылки на пиратские копии и сами фильмы отсутствуют. Названия Marvel принадлежат правообладателям. Официальные постеры не копировались: вместо них авторские геометрические обложки. Приложение не связано с Marvel/Disney. Рекомендуемый по событиям порядок частичный; мультивселенные и многосезонные истории нельзя свести к единственной бесспорной линейной шкале.
